# Como passar o trabalho para outra conta do Claude (guia para a Aline)

## Ideia em uma frase
Tudo o que a próxima IA precisa saber fica na pasta **handoff** deste repositório. Você só passa
**um link** para a outra conta, e ela lê e continua.

## Antes de trocar de conta (na conta atual)
1. Peça: **"atualize o pacote de passagem"**. O Claude atualiza o LEIA-ME.md e o DIARIO.md.
   (O Claude já faz isso ao fim de cada etapa, mas pedir não custa.)
2. Se for continuar um **painel/artefato**, abra o artefato e **baixe o arquivo HTML**
   (ou copie o código). Outra conta não consegue abrir os artefatos desta conta.

## Na outra conta do Claude
1. Abra um **chat novo** (ou um projeto novo).
2. Abra o arquivo [PROMPT-PARA-COLAR.md](PROMPT-PARA-COLAR.md), copie o texto da caixa e cole como
   primeira mensagem. Troque a última linha pelo que você quer fazer.
3. Se baixou o HTML de um painel, **anexe o arquivo** na mesma mensagem.
4. Envie. O Claude vai ler o pacote e te dizer em que ponto estamos.

### Se a outra conta tiver o Claude Code (programação)
Ela também pode **trabalhar direto no repositório**:
1. Em claude.ai/code, conecte o GitHub da conta **alinesielskismelo-png**.
2. Escolha o repositório **Claude-code-**.
3. Cole o mesmo prompt. Assim o Claude consegue atualizar o pacote sozinho.

## Para voltar para esta conta
Faça a mesma coisa ao contrário: peça na outra conta para atualizar o pacote, depois cole aqui:
**"Voltei. Leia o pacote de passagem atualizado: (link)"**.

## Coisas importantes
- **Nenhuma IA sabe quando os créditos vão acabar.** Por isso o pacote é atualizado sempre, e não só
  no fim.
- **Nunca cole senhas ou chaves** no chat de passagem nem no repositório. Ele é público.
- Se o link não abrir na outra IA, abra o LEIA-ME.md no navegador, copie o texto e cole no chat.
